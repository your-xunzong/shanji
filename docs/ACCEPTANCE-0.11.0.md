# 0.11.0 统一验收补充

本包为未签名的 Windows x64 验收包，未作正式发布。包含原有 0.10.2 A1 修复与 0.10.1 中文安装向导；新增生命周期甘特图区间和主工作台改版。不新增云功能，不迁移或批量改写事项。

## 建议顺序

安装前备份现有数据；从托盘退出旧程序后更新，启动后在“关于闪记”确认版本为 0.11.0。不要通过卸载时删除数据来更新。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| A1 | 个人仓库 → 选择仓库位置；先取消，再选中文文件夹并确认 | 系统文件夹窗口确实出现；取消不改配置，确认后显示选定路径；原事项保留。先通过此项再继续依赖仓库的旧 A 项 |
| C1 | 新建明天到期的普通/一次性事项，打开“事项甘特图” | 横条从实际创建时间到截止；月视图不是单个点，日视图能区分同日小时 |
| C2 | 查看已有无截止事项，跨日或应用恢复焦点后刷新 | 从创建到查看时的今天；查看不修改截止或提醒。若只有损坏时间，进入“时间待核对”，不是消失 |
| C3 | 查看持续事件、提前一周的预警事件 | 主条从创建到结束/目标；活动/预警范围在条内标记，不改变实际提醒起点 |
| C4 | 查看已逾期事项；筛选“显示已完成” | 逾期条保留原截止、不延伸到今天；完成条保留原计划并显示完成样式 |
| C5 | 查看月度/年度事项，切到年视图 | 同一事项一行，相邻周期分段；月末与闰日不漂移；缺失的旧周期明确标注“历史未记录” |
| C6 | 切日/周/月/年、前后时间与筛选；点击条和名称 | 日期/区间与所选范围一致；跨窗端部有延续标记；点击打开原事项详情，不新增提醒或事项 |
| C7 | Tab 聚焦事项，↑/↓、Home/End 和←/→；缩小窗口 | 焦点可见、可开详情，名称列与表头固定；时间轴横向滚动，侧栏下方功能仍可访问 |
| C8 | 在隔离开发夹具触发读取失败并重试 | 旧图与原日期标题保留；首次读取失败不能显示成空列表；错误不暴露内部信息，重试可恢复 |

“没有截止”是对数据的展示兜底；快速录入仍按已有 PRD 保存默认有效截止，不为验收新增取消截止的业务操作。旧周期无历史快照时不编造过去的分段；当前已知截止之后的分段是计划预览，不代表已发生或已生成提醒。

## 已验证与待验证边界

- 已运行：前端单元/UI 模拟回归、Rust 领域/数据测试、类型/格式/静态检查、Windows 打包与中文安装脚本检查。
- 已渲染：中文业务内容、月/周区间、已完成筛选、失败保留/恢复、键盘末行焦点、浅色/深色/高对比度/减少动态效果样式和 760×560 窄窗口。
- 尚待实机：新包安装环境 A1、真实中文输入法组合态、系统强制颜色、macOS/Linux 字体/滚动及平台系统能力、完整桌面 P95。模拟与浏览器预览不代替这些验收。

## 可重复的开发预览

从仓库根目录运行 `pnpm dev --host 127.0.0.1 --port 1422`，打开 `http://127.0.0.1:1422/qa/timeline.html`。首次应使用没有已有预览记录的隔离来源；脚本拒绝覆盖已存在的普通预览内容。页面只使用合成数据，底部有主题、一次读取失败和 2000 条示例入口；刷新恢复 12 条中文业务示例。这些入口不进入安装包。

前端主题夹具激活实际 CSS 媒体规则，不修改系统偏好，也不能代替系统强制颜色和本地 WebView 的验证。截图是设计参考，最终外观由用户确认。
