# 0.11.1 提醒设置去重验收

> 本版只整理提醒设置和旧频率兼容逻辑，不改变事项正文、到期时间、提醒历史或数据库版本。安装前先从托盘退出旧程序；启动后在“关于闪记”确认版本为 0.11.1。

## 1. 设置页不再重复

1. 打开“设置”，找到“提醒显示”。
2. 应只看到“系统 / 持续提醒”和“闪记 / 屏幕角落提醒窗”两行。
3. 两行说明均明确“不改变提醒频率”；不再出现“普通事项未确认时重复提醒”及全局分钟数。
4. 两个“发送测试”分别验证 Windows 系统持续通知和闪记屏幕角落提醒窗；关闭一种方式不影响另一种。

## 2. 提醒中心是入口

1. 在同一设置页找到“错过提醒 / 待确认提醒”，数量应与左侧提醒中心及托盘菜单一致。
2. 点击“打开待确认提醒”，设置抽屉关闭并直接打开提醒中心；无待确认事项时显示明确空状态。
3. 此动作不得创建“提醒中心测试”事项，也不得修改现有事项。
4. 制造一条已到期提醒后再次检查数量；完成、暂停或确认看到后，该条及时从中心和托盘数量中消失。

## 3. 频率只服从事项方案

1. 新建普通事项并分别选择“一次性”和“重复”，确认一次性投递后不因旧全局设置再次出现，重复事项按自身时点继续。
2. 新建今日必做，确认它按该事项保存的“强调/强制”等方案及间隔运行；开关“持续提醒”只改变通知形态，不改变下一次提醒时间。
3. 从旧版本覆盖更新且曾启用“普通事项未确认时重复提醒”时，打开并保存一次设置；旧值应被关闭，原事项、提醒历史和到期时间保持不变。

## 4. 界面与平台边界

- 在 760×560、键盘导航、浅色、深色、高对比度和减少动态效果下检查来源标签、开关、测试按钮、数量和打开入口不遮挡。
- Windows 实测持续通知的“完成/15 分钟后提醒/打开闪记”；置顶窗不主动抢走当前输入焦点。
- macOS/Linux 的持续性与通知按钮由桌面环境决定，不支持时应降级到标准通知；仍可使用闪记置顶窗和提醒中心找回。
