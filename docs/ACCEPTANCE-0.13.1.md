## A. 甘特图状态段

1. 新建一个未来截止事项、一个今日必做，并保留一个已逾期事项；再完成一个未到截止事项。
2. 打开“事项甘特图”，分别查看日、周、月、年。
3. 核对横条从创建时间开始：进行中为蓝色；今日必做的有效进行段为绿色；完成后出现绿色段/完成点；未完成逾期从原截止以红色斜纹延伸到今天。
4. 核对原截止仍有竖向刻痕，点击任一色段打开同一事项；切换月份、筛选和刷新后区间不跳动、不重复。

## B. 个人仓库

1. 在设备 A 选择一个空文件夹。确认后应立即提示“已写入 N 条本机记录”，文件夹内出现 `shanji-repository` 和本机 `.sjpack`。
2. 用另一份便携版作为设备 B，选择同一上级文件夹，点击“检查其他设备的数据”。预览应列出新增、已有、冲突和删除数量，未确认前本机不变化。
3. 确认“汇入并更新仓库”。完成后核对设备 B 的事项、类型、标签与待确认提醒；如果原筛选隐藏了新事项，点击“查看全部事项”。
4. 再次同步应没有重复记录。断开仓库或改为只读后重试，应明确说明本机记录是否改变，并保留重新写入入口。

## C. 屏幕角落提醒窗

1. 在后台设置发送“屏幕角落提醒窗”测试，连续重复 20 次；每次点击右上角关闭按钮都应隐藏。
2. 再打开一次并按 `Esc`，窗口应隐藏；中文输入法正在选词时按 `Esc` 不应误关闭。
3. 关闭窗口后核对事项没有被完成、暂停、确认或改成稍后提醒；达到下一次真实计划后仍可再次出现。
4. 若遇到隐藏失败，事项正文、关闭按钮、“完成”“15 分钟后提醒”“打开闪记”必须仍在，能够重试；空载荷窗口也必须有关闭按钮。

## D. 自动更新串联

1. 在维护者确认 GitHub Actions 私钥已配置后，把 v0.13.1 发布为非草稿、非预发布 Release，并上传流水线生成的 `latest.json`、安装/更新包与 `.sig`。
2. 从已安装的 v0.12.0 启用检查更新，应发现 v0.13.1 并显示本版 5 条中文说明。
3. 下载、安装并重启后，“关于闪记”显示 0.13.1，本版说明只自动出现一次；事项数据保持不变。
