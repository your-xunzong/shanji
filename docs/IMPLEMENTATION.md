# MVP 实现状态

## 已完成闭环

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 快速录入 | 已实现 | 独立置前窗口、自动聚焦、Enter 保存、Shift+Enter 换行、Esc 隐藏、草稿恢复 |
| 全局快捷键 | Windows 已验证启动 | 默认 `Ctrl/Cmd + Shift + Space`，冲突时应用继续启动并提示后台换键 |
| 本地持久化 | 已实现 | SQLite + WAL，Rust 单一写入口，事项/初始事件/草稿清理同事务 |
| 默认到期 | 已实现 | 后台配置工作日与默认时间，下班后/非工作日创建转下一工作日 |
| 自动顺延 | 已实现 | 普通默认事项跨日后顺延；保留次数和事件；今日必做不顺延 |
| 今日必做 | 已实现 | 到期后按 5–240 分钟间隔重复，支持勿扰、暂停、恢复和完成停止 |
| 时间调整 | 已实现 | 未完成事项（含逾期事项）可改为新的本地日期时间，后端重建提醒计划并写入事件记录 |
| 类型与标签 | 已实现 | 自定义增删改、颜色、排序；类型单选、标签多选，删除关系不连带删除事项 |
| 事项编辑/回收站 | 已实现 | 完整编辑、完成/恢复、软删除与短时撤销、30 天回收站和永久删除确认 |
| Excel 导出 | 已实现 | 按日期、状态、类型和标签筛选；生成明细/汇总工作表并防止公式注入 |
| 提醒幂等 | 已实现 | 事项 ID + 计划时间 + revision；同一到期周期不重复发送 |
| 系统通知 | Windows 运行路径已接入 | 后台设置与 `--test-notification` 可创建约 10 秒到期的真实测试事项；macOS 需补授权引导 |
| 持续提醒 | Windows 已接入 | 今日必做优先使用原生 Reminder 场景；可选置顶提醒窗不主动抢焦点并支持多事项排队 |
| 提醒中心 | 已实现 | 待确认事项与托盘数量来自 SQLite；完成、暂停、稍后提醒或明确确认后同步移除 |
| SMTP 邮件 | 已实现、默认关闭 | TLS/STARTTLS、按标签路由、首次到期默认只发一次、1/5 分钟有限重试；密码只进入系统凭据存储 |
| 托盘/单实例 | Windows 已接入 | 关闭窗口隐藏；托盘可快速记录、打开、退出；双击托盘图标打开主窗口 |
| 后台设置 | 已实现 | 默认时间、工作日、间隔、勿扰、快捷键、五种提醒测试与邮件渠道设置 |
| Windows 分发 | 已实现 | NSIS 安装程序与带 `portable.flag` 的便携 ZIP |
