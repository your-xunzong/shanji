# ADR 0003：开机启动状态与版本化首次引导

- 状态：已接受
- 日期：2026-08-28
- 对应版本：0.2.0

## 背景

开机启动属于操作系统外部状态，数据库中的布尔值不能证明登录项真实存在。首次引导还需要对新安装和升级用户只展示一次，同时允许用户主动重新打开。

## 决策

1. 继续使用已引入的 Tauri autostart 插件，不新增常驻服务或平台脚本。
2. SQLite 保存用户期望的开机启动值和已完成的引导版本；每次读取设置时以操作系统查询结果覆盖展示值。
3. 修改设置时先校验快捷键，再变更系统快捷键和开机启动，最后提交 SQLite；任一步失败都尽力恢复变更前的系统状态，且不把失败状态写成成功。
4. 开机启动统一传入 `--background`，由现有启动装配隐藏主窗口。
5. 引导完成状态采用单调递增版本号，不使用仅存于前端的 localStorage；点击跳过只记录引导完成，不修改系统选项。
6. 便携版启动项指向当前可执行文件路径，因此界面必须提示移动目录会导致失效。

## 影响

- 数据库 schema 增加开机启动期望值和引导版本，并提供版本化迁移与迁移备份。
- Windows、macOS、Linux 通过同一适配入口读写，但错误文案和不支持情形按平台降级。
- 外部程序仍可能修改系统启动项；设置页重新打开时会再次查询并纠正展示，不静默覆盖用户在系统中的选择。
