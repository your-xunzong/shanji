# ADR 0005：类型标签关系、回收站与本地 Excel 导出

- 状态：已接受
- 日期：2026-08-28
- 适用版本：v0.4.0 起

## 背景

类型表示事项的工作性质，只能单选；标签表示工作内容，可以多选。两者需要支持用户维护，同时不能因删除整理方式而误删事项。用户还需要把本地数据整理为常见办公软件可读的报表。

## 决策

1. 延续 `categories` 作为类型表，新增 `tags` 与 `item_tags` 多对多关系。类型和标签均通过持久化 `position` 排序，所有写入只经过 Rust 数据层。
2. 删除类型前必须把关联事项迁移到另一类型或收件箱；删除标签只级联清理 `item_tags`。两种操作都不修改事项正文、状态和提醒时间。
3. 事项删除先写为 `DELETED` 并保留原状态，立即取消提醒；30 天后由既有低频后台维护清理。永久删除仅允许对回收站事项执行。
4. Excel 使用 `rust_xlsxwriter` 在本机生成标准 `.xlsx`，不依赖已安装的 Excel。先写临时文件，成功后再替换目标文件；用户文本按公式注入规则转义。
5. 文件位置使用 Tauri 官方对话框插件由用户主动选择。导出查询可按创建日期、状态、类型和标签组合筛选，回收站不进入报表。
6. 托盘优先处理平台提供的双击事件，同时对可收到连续单击事件的平台做短间隔识别；不支持托盘事件时保留菜单入口。

## 影响

- 优点：类型、标签和事项生命周期语义清晰；报表全程离线、可恢复且不需要大型运行时。
- 代价：`.xlsx` 写入库会增加少量包体积；回收站占用空间最长 30 天，但避免误删。
- Windows：支持原生文件保存对话框和托盘双击，已列入本版本安装验证。
- macOS：文件对话框可用，托盘原生双击与连续单击识别均保留，需真实设备验证焦点行为。
- Linux：文件对话框可用；部分桌面环境不发送托盘点击事件时，降级为托盘菜单“打开闪记”。
