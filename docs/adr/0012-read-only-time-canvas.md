# ADR-0012：由领域层生成只读时间画布投影

- 状态：已接受
- 日期：2026-09-03
- 关联版本：v0.10.0

## 背景

七种事件拥有不同的时间语义：到期点、预警区间、持续区间和月度/年度日历周期。若前端自行推算，月末、闰日、时区和未来领域规则容易与提醒调度分叉；若首版允许拖动，还会把逾期边界和周期修改引入高风险写路径。

## 决策

1. Rust 接收缩放、锚点与筛选条件，返回可见范围、今日线、只读时间条、里程碑、目标点和未排期事项。
2. 日、周、月、年范围与月度/年度实例均按当地日历计算，不把月或年换成固定天数。前端只把返回日期映射到像素，不生成业务日期。
3. 普通、一次性、今日必做显示到期里程碑；持续显示闭区间；预警显示预警区间与目标点；月度/年度只展开当前视窗实例。
4. 无法形成完整时间语义的记录进入未排期区，不伪造开始时间。损坏时间跳过并返回去敏计数，不在页面显示内部字段或原始解析错误。
5. 首版没有修改命令、拖拽把手、依赖关系或资源计算。点击条目只复用现有事项详情入口。

## 影响

- 不引入图表库；使用 Svelte、原生 CSS 和现有日期依赖，避免增加包体积和 canvas 可访问性负担。
- 大数据量先在 Rust 按视窗和筛选裁剪；响应附带总数和截断状态，UI 不一次创建十万个 DOM 节点。
- 三平台共享领域投影；字体度量与滚动条可以平台降级，但日期和键盘焦点语义一致。

## 被否决的方案

### 在浏览器端展开所有周期

这会重复领域规则并难以稳定测试时区边界。

### 首版支持拖动改期

只读验收尚未完成前加入写入，会把点击误触、周期修改和逾期保护混入同一版本。
