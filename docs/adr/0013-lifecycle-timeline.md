# ADR-0013：生命周期区间、可注入时区与虚拟行

- 状态：已接受；2026-09-07，v0.11.0
- 替代：ADR-0012 中到期里程碑、静默跳过损坏时间和前端生成刻度的决策。

Rust 从同一只读查询取得创建、有效截止、活动/预警时间及持久化周期锚点。投影接收时钟值与可注入时区，输出刻度、真实边界、归一化条位置及条内强调区间；前端不推算业务日期。日视图按实际 UTC 时长定位，以适应 23/25 小时日；更大范围按当地日期定位。

不增加数据库迁移，不回写事项或提醒；旧数据只有当前周期截止而没有首次截止历史，返回明确的历史不完整标记，仅从已知截止向未来展开，不据此反推历史。首条主区间仍准确表达创建到当前已知截止的存续范围，不代表其中没有发生其他周期。

同一事项的周期在前端合为一行。日期表头、名称列与轨道使用同一滚动坐标系；行高固定、可见行加缓冲虚拟渲染，键盘移动先滚动后聚焦。失败保留已成功载入的数据，竞态只接受最近请求。

保持 2000 个区间/200 条待核对载荷上限并返回实际总数；不引入图表库、网络字体或生产依赖。三平台共享算法，原生字体与滚动条可不同；高对比度使用边框和端帽表达状态。账户、云空间与同步不在本次实施范围。

载荷上限之外继续校验时间与计算可见段总数，但不构造标题副本、日期说明和位置展示字段；该优化不改变异常计数或周期边界，避免 10 万条数据都付出只需 2000 条的展示格式化成本。
