# 闪记 v0.13.1

- 甘特图改为展示事项从创建到截止、完成或今天的完整过程，并用连续色段区分记录、进行、完成和逾期。
- 逾期事项保留原截止标记，同时用红色斜纹延伸到今天，能够直接看出逾期时长。
- 选择个人仓库后会立即写入本机快照；同步前先检查其他设备的数据，汇入后刷新事项、类型、标签和待确认提醒。
- 个人仓库会明确显示本机快照是否写入成功，失败时可单独重试，不会误报同步完成。
- 屏幕角落提醒窗新增始终可用的关闭按钮和 Esc 操作；关闭失败时保留事项与重试入口，关闭不会误改事项状态。

## 平台与升级说明

平台支持：发布流水线提供 Windows x64 安装版与便携版、macOS Universal DMG，以及 Linux x64 AppImage 和 DEB；Windows 便携版与 Linux DEB 只提供手动升级入口。

数据迁移：数据库结构保持 v11，不需要手工迁移；启动时仍会先创建可恢复备份并校验数据。

签名状态：应用更新附件使用闪记更新私钥签名；Windows Authenticode 和 macOS 公证尚未配置，系统仍可能提示未知发布者。

已知降级：Windows 已完成自动检查、构建、中文安装脚本和便携包验证；macOS/Linux 的角落窗、同步盘原子写入与原地更新仍待实机复核。
