# 闪记 v0.13.3

- 重要事项现在可以设置默认提醒方案；切换事件类型或重要标记时自动匹配最新默认，也能为单条事项另行修改并随时恢复默认。
- 已完成事项可以从后台恢复为未完成。原内容、分类和历史保留，系统只重算未来提醒，不补发已过期的一次提醒。
- 新增月度、季度 Word 小结，可使用自己的 `.docx` 模板；“导出与小结”面板会说明占位符应放在正文还是表格模板行。
- 个人仓库会区分完全重复和有差异的冲突：完全相同内容可自动收束，有差异时选择保留本机、保留仓库或两份都保留。
- “重复”提醒可在系统设置中开启完整通知，额外显示事件类型、类型、标签和下一次提醒；其他提醒方式不变。

## 平台与升级说明

数据迁移：数据库结构从 v11 升级到 v12，启动时先创建可恢复备份；旧事项不会被新的默认提醒方案批量改写。

隐私：Word 小结和仓库整理均在本机完成。通知详情不包含备注，模板无效或输出失败时原文件保持不变。

已知降级：系统通知可见行数仍由 Windows、macOS 和 Linux 的通知服务决定；内容被截断时可点击通知打开事项。macOS/Linux 的 Word 兼容性和同步盘原子替换仍需实机复核。
