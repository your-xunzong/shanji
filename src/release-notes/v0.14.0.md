# 闪记 v0.14.0

- 强制提醒间隔现在可在后台设置为 5–240 分钟；通知按钮、屏幕提醒窗和待确认提醒会显示并执行事项实际保存的分钟数。
- 双击事项卡即可进入编辑，文本输入时按 Enter 快速保存；Shift+Enter 可继续在备注中换行，中文输入法候选确认不会误保存。
- 待处理、今天、已逾期、已完成、回收站和全部事项会分别显示真实数量，也可在后台统一隐藏。
- 更新检查会并行连接 GitHub 与 Gitee，同版本自动选择响应更快的来源；一个来源不可用时可从签名一致的另一来源继续。
- 双源发布使用同一次构建和同一签名；两个来源的同版本签名不一致时，闪记会拒绝镜像并改用 GitHub 规范源。

## 平台与升级说明

数据迁移：数据库结构从 v12 升级到 v13，启动时先创建可恢复备份；已有事项、提醒方案和单条提醒间隔保持不变。

联网授权：v0.14.0 的自动更新会访问 GitHub 与 Gitee。旧版仅授权 GitHub 的选择不会自动扩展，升级后需要重新确认；手动检查仍由用户主动触发。

已知降级：macOS 和 Linux 的系统通知操作能力由桌面环境决定；没有原生操作按钮时，可打开闪记在待确认提醒中使用相同间隔。
